# DM Templates

How I write the 1 message people get after they comment. Remember Meta's rule: the app can send only 1 automatic message unless they reply, so this message must do the whole job.

## How to use this file

1. Read the 4 part formula and my real DM.
2. Pick the template for your offer type.
3. Replace every slot in square brackets, like `[THING]`, with your real words.
4. Check it against the rules at the bottom.
5. Paste it into your app (see `05-VYRAL-SETUP.md`).

## The 4 part formula

| Part | What it says | Length |
| --- | --- | --- |
| 1. Hello plus what it is | A warm 1 line hello that names the thing | 1 line |
| 2. The link | Just the link, on its own line | 1 line |
| 3. What it does for them | 1 line on the result they get | 1 line |
| 4. The easiest way to use it | The simplest first step | 1 to 2 lines |

## My real DM (worked example)

This is the exact DM people got when they commented SHOW on my Reel:

```
Hey! Here's the free Show, Don't Tell AI skill 👇
https://github.com/onittindwani-ai/show-dont-tell-ai-skill
Paste in your website, sales email or pitch, and it rewrites it to show the result first, with real proof and one clear next step.
Easiest way to use it: give Claude the link and say "set this skill up for me". Or just open the paste-in prompt file and use it in ChatGPT or Claude.
```

### Why each line works

| Line | Part | Why it works |
| --- | --- | --- |
| "Hey! Here's the free Show, Don't Tell AI skill 👇" | Hello plus what it is | It is warm, it says "free", and it uses the same name as the Reel, so they know it is the right thing. The 👇 points to the link |
| The GitHub link | The link | On its own line, so it is easy to tap. Only 1 link, so there is no choice to make |
| "Paste in your website, sales email or pitch, and it rewrites it..." | What it does for them | It names 3 things they already have, and the result they get. No hype words |
| "Easiest way to use it: give Claude the link..." | The easiest way to use it | It gives a first step that takes seconds, plus a backup for people who use ChatGPT. They do not have to install anything by hand |

It is about 65 words, counting the link. It reads like a friend sending a link, not like an ad.

## Fill in templates by offer type

Each one follows the 4 parts. Replace the slots.

### 1. GitHub repo or AI skill

```
Hey! Here's the free [SKILL NAME] 👇
[GITHUB LINK]
It [WHAT IT DOES IN 1 LINE].
Easiest way to use it: give Claude the link and say "set this up for me". Or open the prompt file and paste it into ChatGPT or Claude.
```

### 2. PDF or guide

```
Hey! Here's my [GUIDE NAME] 📄
[LINK]
It shows you [THE RESULT] in [NUMBER] simple steps.
Easiest way to use it: open it on your phone and do step 1 today.
```

### 3. Notion page

```
Hey! Here's the [PAGE NAME] I use 👇
[NOTION LINK]
It has [WHAT IS INSIDE] so you can [RESULT].
Easiest way to use it: tap "Duplicate" at the top right to save your own copy.
```

### 4. Product link

```
Hey! Here's the [PRODUCT] from the Reel 👇
[LINK]
I use it for [REAL USE] and it [WHAT YOU LIKE ABOUT IT].
Easiest way to choose: start with [SIZE OR VERSION] if you are new to it.
```

### 5. Affiliate link (with honest disclosure)

```
Hey! Here's the [PRODUCT] I mentioned 👇
[AFFILIATE LINK]
I use it for [REAL USE].
Heads up: this is an affiliate link, so I may earn a small amount if you buy, at no extra cost to you.
```

### 6. Discount code

```
Hey! Here's your code for [BRAND OR PRODUCT] 🎁
Code: [CODE] at [LINK]
It takes [AMOUNT] off until [END DATE].
Easiest way to use it: paste the code at checkout. [IF PAID PARTNERSHIP: I'm partnered with them on this.]
```

### 7. Waitlist

```
Hey! Here's the waitlist for [THING] 👇
[WAITLIST LINK]
You'll be first to know when [WHAT HAPPENS] on [DATE OR "soon"].
It takes about [NUMBER] seconds: just add your name and email.
```

### 8. Booking a call

```
Hey! Here's the link to book a free [LENGTH] minute call 📅
[BOOKING LINK]
We'll look at [THEIR PROBLEM] together and you'll leave with [1 CLEAR OUTCOME].
Easiest way: pick any time that suits you. No pressure if now is not the right time.
```

### 9. Free trial

```
Hey! Here's the free trial for [TOOL] 👇
[LINK]
It lets you [RESULT] without paying for [TRIAL LENGTH].
Easiest way to start: [FIRST STEP]. Set a reminder if you do not want to keep it after the trial.
```

### 10. Playlist or video

```
Hey! Here's the full [VIDEO OR PLAYLIST] 🎬
[LINK]
It walks you through [TOPIC] from start to finish.
Easiest way: watch the first [NUMBER] minutes, that is where [THE KEY PART] is.
```

### 11. Checklist

```
Hey! Here's my [TOPIC] checklist ✅
[LINK]
It is [NUMBER] boxes to tick so you do not miss [THE COMMON MISTAKE].
Easiest way to use it: screenshot it and tick it off before you [ACTION].
```

### 12. Follow gated resource

Only use this if your app supports Follow Unlock and the offer is worth a follow. Be clear about it in the Reel.

```
Hey! Thanks for the follow 🙌 Here's the [THING] 👇
[LINK]
It helps you [RESULT].
Easiest way to use it: [FIRST STEP].
```

### 13. Prompt pack

```
Hey! Here's my [TOPIC] prompt pack ✍️
[LINK]
[NUMBER] prompts you can copy and paste to [RESULT].
Easiest way to use it: start with prompt 1 and swap in your own details.

### 14. Template (Canva, Sheets, Docs)

```

[LINK]
It is ready to fill in, so you can [RESULT] in a few minutes.

## Follow up messages (when someone replies)

The app can send more only after they reply, and only within 24 hours. I prefer to answer these myself.

### They say thanks

```
You're welcome! What are you going to use it for?
```

```
Glad it helps 🙌 Tell me how it goes.
```

### They ask a question

```
Good question. [SHORT ANSWER IN 1 TO 2 LINES]. Want me to send the exact step?
```

```
Yes, it works for [THEIR CASE]. Just [THE 1 CHANGE THEY NEED].
```

### "It didn't work"

```
Sorry about that! What do you see when you open it? A screenshot helps.
```

```
Try this: [SIMPLE FIX]. If it still doesn't work, tell me and I'll send another way.
```

```
The link sometimes opens in the Instagram browser. Tap the 3 dots and choose "Open in browser", then try again.
```

### They want more

```
Love that. I'm posting [NEXT TOPIC] soon. Here's 1 more that fits: [LINK]
```

```
Here's the next step if you want to go further: [LINK OR TIP]. No rush.
```

## Rules

- [ ] Under about 70 words (my real DM above is about 65, counting the link).
- [ ] Exactly 1 link (a second link only if a code needs its shop link).
- [ ] Uses the same name for the thing as the Reel did.
- [ ] No hype ("insane", "game changer", "guaranteed").
- [ ] No pressure ("only 2 left!", "reply in 5 minutes").
- [ ] Affiliate links and paid partnerships are disclosed in the DM.
- [ ] No promise of results you cannot back up.
- [ ] No passwords, private links or personal data.
- [ ] The link opens on a phone, in a private browser window.
